# Agent instructions

Public support/privacy documentation for Shinkoiwa; game source remains in its separate private repository.

## Shinkoiwa identity and tooling

Shinkoiwa Sardistic and its support site have their own identity. The game repository owns the approved app mark, palette, typography, iconography, animation and Store presentation. Support uses approved game exports and records their provenance. See `.agent-tools/PROJECT_CONTEXT.md`.

Use branding-neutral Mac tooling for tests, profiling, builds, signing and releases. Keep GitHub Actions disabled. Follow the future language requirements in PROJECT_CONTEXT.md; record actual language coverage and native RTL evidence separately. Verify current Apple requirements when preparing an authorized release.
