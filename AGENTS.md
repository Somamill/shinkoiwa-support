# Agent instructions

Public support/privacy documentation for Shinkoiwa; game source remains in its separate private repository.


## Project scope

This repository is outside the dot. product registry. Use its own identity and design requirements. For reusable Mac validation and release tooling, see [Mac Development Tools](https://github.com/Somamill/mac-development-tools). Configure project checks explicitly.

Use the game project’s approved Shinkoiwa media for public help and record the source build in media/README.md. Keep help, privacy, licensing and release claims aligned with the version players can install.
